# amazingmaps

用于论文制图与空间分析的地图生产项目。

## 任务目标
本项目的目标是围绕经济与空间数据，构建可复现的分析与制图流程，支持从探索性分析到论文发表级可视化的完整工作链路。

## 运行环境
- 操作系统：Linux / macOS / Windows（建议优先使用 Linux）
- Python：3.10+
- 建议工具：Jupyter Notebook 或 VS Code
- 地理与科学计算常用库（按需安装）：`geopandas`、`rasterio`、`scikit-learn`、`matplotlib`、`seaborn`、`contextily`

## 包含的地图种类
1. grid analysis
2. KDE cluster detection
3. commercial corridor extraction
4. PCA economic axis
5. profile curves
6. publication maps

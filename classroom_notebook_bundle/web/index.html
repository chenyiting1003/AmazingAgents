Mini Model UN · Global AI & Climate Adaptation Fund (classroom lab)

Use this page to inspect simulation outputs in the browser. Run a simulation locally so files exist under outputs/, then click Refresh results.

What are we simulating?

A UN-style discussion on whether to create a “Global AI and Climate Adaptation Fund.” Case materials live in case_materials/: seed_un_ai_climate_governance.txt (background), prediction_request.txt (task, five parties, three agenda rounds).

Important: outputs are a fictional negotiation exercise for learning and validity discussion, not a prediction of real events.

How do I produce outputs?

  • Configure .env (this course defaults to DeepSeek: API key, https://api.deepseek.com, model name; see course notes for OpenAI).
  • Activate your virtual environment and install: pip install -r requirements.txt
  • Generate baseline: open and run Mini_Model_UN_Student_Lab.ipynb from the repo root (or, for debugging, python scripts/run_minisim.py).
  • In another terminal, start this web server (pick one):
    python scripts/serve_lab_ui.py (default http://127.0.0.1:8080/)
  • Return here and click Refresh results; explore each tab, or use Continue discussion to issue instructions for follow-on rounds (extra API usage applies).

If the page is blank or errors persist: confirm the address bar shows a local URL such as http://127.0.0.1:8080/, not file://... from opening the HTML file directly.

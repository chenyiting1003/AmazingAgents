# Validity Critique Worksheet (Model UN Classroom Simulation)

> This worksheet evaluates an assumption-driven social simulation. It does **not** validate factual prediction.

## 1) Scenario framing
- What scenario question was simulated?
- Which assumptions were explicit?
- Which assumptions were implicit?

## 2) Stakeholder realism
- Did each stakeholder stay consistent with assigned interests?
- Which statements seemed role-played vs evidence-based?

## 3) Negotiation dynamics
- Where did conflict intensify?
- What concessions emerged?
- Which turning points shaped the possible partial agreement?

## 4) Evidence and uncertainty
- Which claims need real-world evidence?
- Which claims were plausible but unverified?
- What uncertainty most changed interpretation?

## 5) Limits and bias
- What model/provider limitations might affect outputs?
- What framing bias appears in prompts/roles?
- Which voices are missing from the simulation?

## 6) Conclusion
- Why is this output a scenario deliberation rather than a factual prediction?
- What data and methods would be needed for a stronger empirical study?

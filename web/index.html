Mini Model UN · 全球 AI 与气候适应基金（课堂实验台）

本页用于在浏览器里查看模拟结果。请先在本机运行模拟生成 outputs/ 下的文件， 再点击「刷新结果」。

我们在模拟什么？

联合国层面讨论是否设立「Global AI and Climate Adaptation Fund」。仓库里的材料在 case_materials/： seed_un_ai_climate_governance.txt（背景）、 prediction_request.txt（任务与五方、三轮议程）。

重要：输出是架空谈判推演，用于学习与效度讨论，不是对现实的预测。

怎么跑出结果？

  • 配置 .env（OpenAI 官方 Key 与模型名，见课程说明）。
  • 激活虚拟环境并安装依赖：pip install -r requirements.txt
  • 运行：python scripts/student_run_lab.py 或 python scripts/run_minisim.py
  • 在本机另开一个终端运行本网页服务（二选一）：
    python scripts/serve_lab_ui.py（默认 http://127.0.0.1:8080/）
  • 回到浏览器，点击 刷新结果；可查看 baseline 各标签，或在 继续讨论「指令」 里对代表方下指令生成续轮（会额外扣 API 费用）。

若页面空白或状态一直报错：请确认地址栏是 http://127.0.0.1:8080/ 这类本地网址， 而不是 file://... 直接打开硬盘上的 html。
